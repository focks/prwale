# Security Policy

prwale reads PR and Jira content through your existing `gh` and `jira` CLI sessions and stores a local cache under `~/.prwale` or `PRWALE_HOME`. Do not include cache files, credentials, or private PR content in public reports.

For a suspected vulnerability, use GitHub's private vulnerability reporting for this repository when available. Otherwise, contact the maintainer privately through the contact information on the [focks GitHub profile](https://github.com/focks). Include reproduction steps and affected versions. Please avoid opening a public issue until the maintainer has had a chance to investigate.
